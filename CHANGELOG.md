# Changelog

All notable changes to Aegis are documented in this file.

## [Unreleased]

### Added
- `test-core.mjs`: tests for the frozen value of a disposed computed and for the caching semantics of `untrack()` inside a computed.
- README “Verified by design”: what the node suite proves, what only the browser suite covers, and the limits the tests do not promise (E001 is a reported leak, `untrack()` caches, E027 is a ceiling, contracts are sampled in dev, unhandled effect errors go to `reportError`).

### Changed
- An effect error with no `onError` / `scope.onError` in an environment without `reportError` and without `window` (node, workers) is logged with `console.error` instead of being rethrown from a timer; in browsers the behaviour is unchanged (uncaught error, page keeps running).
- The file header no longer claims “bugs impossible by design”; it names what the architecture prevents and what the dev build reports.

### Fixed
- `computed.dispose()` now freezes the value as E045 promised: a disposed computed no longer recomputes on `value`/`peek()` when a source changes (the non-live durability check ignored the disposed flag).

## [0.7.0] — 2026-09-04

### Added
- `modal()` closes the dialog on a backdrop click (the `<dialog>` element itself is the click target, its content never is) and closes with an empty `returnValue`, so a later Escape does not report the previous button.
- `?aegis-devtools` in the page URL loads `aegis-devtools.js` next to the module at startup; the inspector opens itself. Previously only `dev.panel()` loaded it.
- `aegis.d.ts`: six JSDoc blocks (`onWarn`, `dev`, `watch`, `fieldArray`, `register`, `TranslationFunction`) sit directly above the export they describe.
- Web platform, phase C2 — router guards and redirects run before the navigation commits (`NavigateEvent.intercept({ precommitHandler })`, Chromium 138+): one history entry, no URL flicker, a blocked navigation never touches the URL; older browsers keep the old path; routes compile to `URLPattern` where available (`:id([0-9]+)` — `\` is the URLPattern escape character, so write `[0-9]`, not `\d`, `{/:lang}?`, suffixes — the platform's own grammar with decoded groups, regex fallback otherwise); `trap({ escape })` uses `CloseWatcher` so Esc, Android back and assistive-technology close requests share the platform stack with `<dialog>` and popovers (`escape: 'key'` forces the keydown path); `portal(target, fn, { popover, anchor, placement })` renders in the top layer with light-dismiss and an `open` signal; `command()` follows the Invoker Commands spec: custom commands are `--name`, `commandfor` is the target and built-in commands only get `aria-expanded` sync; persisted cache records above 2 KB are gzip-compressed with `CompressionStream` (5–10× more data in the same byte budget, `put()` as a memcpy instead of a structured clone) and byte sizes are real bytes
- Router guards that are synchronous now decide inside the `navigate` event itself: a block is `preventDefault()`, a redirect cancels and re-navigates with the same history kind — no microtask before `pending` flips, no precommit round-trip; only asynchronous guards use `precommitHandler`, and browsers without it await the same promise once (guards never run twice).
- Security, phase C1 — attribute sinks are typed at compile time from the static prefix: a URL attribute whose value can choose the scheme goes through `_safeUrl` (javascript:/data:/vbscript: → `about:blank`, S002) while `href="/u/${id}"` costs nothing forever; `on*` attributes refuse strings (S003); `srcdoc` / `.innerHTML` / `.outerHTML` accept only `TrustedHTML` or `trusted()` (S004); `html()` without the template tag now throws (only a frozen template object may become HTML); Trusted Types — one passthrough policy `aegis` for template literals, `configure({ trustedTypes: { server } })` for server HTML, `_parseHTML` is the single string→DOM door for `swap`/`boost`/`wireForm` (with Declarative Shadow DOM via `parseHTMLUnsafe`/`setHTMLUnsafe` or a polyfill, `swap({ sanitize })` via the Sanitizer API or a minimal scrub, and shadow-root morphing); islands — `data-aegis-src` obeys an origin policy (same-origin by default, S006), islands inside `[data-aegis-untrusted]` mount only from `configure({ islands: { allow } })` (S007), `data-aegis-props` must point inside the island (S008), `data-aegis-integrity` gives SRI to dynamically imported islands (S010), `sanitizeConfig` for DOMPurify; requests — flat `configure({ headers })` and the CSRF token go only to trusted origins (own, `baseURL`, `configure({ origins })`), per-origin headers `{ 'https://api.example': {...}, '*': {...} }`, `_sameOrigin` fails closed, S009 in dev for credential headers to third parties; persistence — `configure({ cache: { scope } })` binds IndexedDB records and the offline queue to a principal (foreign records are not hydrated, foreign mutations are never replayed under the current session), `Cache-Control: private`/`no-store` and `Vary: Cookie` are never persisted, `redact` strips token query values from cache keys, `cache.purge()` for logout; - Islands and holes, phase B4 — a reactive hole that returns the same `html\`\`` template with different primitive values is patched in place (text and single attributes written into the existing nodes, focus and element identity kept) instead of torn down and rebuilt; islands can hibernate: `data-aegis-hibernate` freezes an island whose subtree is skipped by rendering (`content-visibility`) — its state is snapshotted, the scope destroyed, the DOM kept — and re-mounts it on return; working-set paging for `visible` islands: `data-aegis-resident="2000px"` or `hydrate(root, { resident: { margin, max } })` pages an island out with a snapshot when it scrolls that far away and back in when it approaches, with CLOCK second-chance replacement over the resident set; `ctx.state(key, init)` is a signal that survives hibernation and paging (`data.snapshot`, `data.resume` on re-mount, `api.snapshot()` for custom state); islands in focus, `data-aegis-permanent`, playing media or unsaved input are never evicted; `stats().islands` reports residents, evictions and hibernations
- morph, phase B3 — children are matched by Heckel's unique-fingerprint anchors (tag, id/key/name/href, leading text) extended to neighbours, with authored `id`s as the strongest pass and idiomorph-style id-set soft matching for the rest, then ordered by LIS so only nodes outside the longest stable run move (via `moveBefore`): inserting one `<li>` at the top of 1000 unkeyed rows keeps all 1000 nodes and writes nothing into them, moving row 99 to the top is one move instead of 99; a level with fewer than 30 % shared ids and no live islands is replaced as a subtree instead of morphed node by node; `checked` is never written into the radio group the user is interacting with (precedence bug fixed); random-tree oracle `from.isEqualNode(to)` in the suite
- list(), phase B2 — reconciliation without hash-table churn (generation stamps and per-entry positions instead of three Maps/Sets per pass, LIS in reusable Int32Array scratch, new rows inserted as fragment runs, moved rows via `Node.moveBefore()` so focus, selection, iframes, video and running animations survive a reorder); reactive arrays keep a splice log and `list()` applies the delta directly (`push`, `splice`, `unshift`, index writes: O(|Δ|) DOM work instead of re-keying and re-diffing the whole array; `sort`/`reverse` reset to a full pass); immutable updates get an identity prefix/suffix trim so a one-item change computes keys only for the middle; a cost-based planner picks `rebuild` (one Range extract + one fragment insert, row scopes untouched) over `keyed` for large reorders and mass removals — `dev.plans()` is the EXPLAIN ANALYZE; big inserts under `startTransition` or input are built in slices with viewport-first order, an optional `pending` signal and `aria-busy` on the container; `{ transition: 'view' }` batches every list of a flush into one `document.startViewTransition()` with unique `view-transition-name`s per row (native FLIP); `{ hibernate: true }` freezes rows whose container is skipped by rendering (`contentvisibilityautostatechange`) — scopes disposed, DOM kept as a snapshot, re-rendered on return
- Template engine, phase B1 — templates compile to a walk program: parts are numbered in document order and instantiation is one monotone cursor (firstChild / nextSibling / parentNode opcodes) over `document.importNode` clones instead of a root-relative `childNodes[]` walk per part; compile-time whitespace normalisation drops render-irrelevant whitespace text nodes under tables/lists and at the template edges and collapses newline runs (30–50 % fewer nodes per clone); every binding gets a committer specialised on its static facts (type, name, tag) at compile time, with event modifiers parsed once per template, custom-element values that are objects/arrays/numbers set as properties (Vue's rule) and property-only names (`indeterminate`, `srcObject`, `muted`, …) always set as properties; inline caches per part fold a primitive that arrives twice in a row into the master template so later clones pay nothing (a miss unfolds it and goes megamorphic); hole fusion drives all function-valued text/attribute/boolean/property holes of one instance with a single effect and per-slot memo, demoting a hole that returns a Node to its own effect. bench.html: create 1000 rows 19.7 → 14.4 ms, create 10 000 162 → 113 ms, html`` × 1000 6.0 → 2.7 ms, append 1000 17.9 → 10.6 ms

- Reactive core, phase A2 — dispose is a transaction: `scope.dispose()`, `effect` disposal and every effect re-run happen inside a batch, so a cleanup that writes a signal no longer runs sibling effects of the dying subtree over half-destroyed state (outside observers see one consistent post-state); one ownership edge per disposable — an effect, subscription or listener created inside an effect run is owned by that run only (`_kids`), not by the scope as well, which makes ownership checkable; runtime contracts in dev — after every flush the engine verifies subscriptions ⇔ dependencies, live computed ⇔ observed, no disposed observer in `subs`, nothing stranded in the queue, scope children ⇔ parent, and reports E051 (`dev.contracts = 'strict' | 'sampled' | false`; the browser suite runs strict, so ~1000 asserts now check the invariants on every flush); the cache checker also audits the SIEVE list ⇔ Map, the byte ledger and the hand; `list()` moves are asserted against the exact `mid − |LIS| + inserts` bound on random permutations

- Reactive core, phase A1 — one hidden class per Signal/Computed/Effect (a shared `_Src` base, fields initialised in a fixed order, a Smi flag word instead of nine booleans); zero-garbage flush (double-buffered queue, sortedness tracked at enqueue, error list allocated lazily); O(1) dependency de-duplication by run stamp, so interleaved reads of the same source occupy one slot; value-anchored versions — a write-and-revert inside one batch, effect run or flush round keeps the old version and re-runs nothing (Salsa backdating applied to inputs); durability levels `signal(v, { durability: 'low' | 'medium' | 'high' })` — a derived value of a rarely-written signal is not re-verified after unrelated writes, and a computed with no sources is a constant; provenance-ordered rounds — an effect that writes a signal read by an earlier effect teaches the scheduler an edge, the round is sorted by Kahn with creation-order priority so the reader runs once (not stale-then-correct), and a write cycle is reported by E027 with the effect names in the very first round.
